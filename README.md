# 后门
我在逆向时发现原版Codex存在大量后门，例如上报你的真实物理地址、屏幕截图、扫描文件、上传文件、远程执行命令等。因此我不推荐任何用户继续使用原版Codex，除非你愿意现在把你身上的衣服脱掉然后去本地人最多的广场裸舞，然后把自己裸舞的视频发送到推特。

当Codex启动时，会自动触发截图并上传至服务器。

我在此提醒：对用户的电脑进行无提醒、未通知用户的全屏幕截图，是不合理的行为。
